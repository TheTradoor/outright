# Security

Outright is in development. There is no supported production release or deployed
Outright market. The inherited Percolator engine is unaudited and must not be
used with real funds.

## Report a vulnerability

Use GitHub's [private vulnerability reporting](https://github.com/TheTradoor/outright/security/advisories/new)
for this repository. Do not publish exploit details in an issue or pull request
before the report has been assessed.

Include the affected commit, relevant files or instructions, a minimal
reproduction, the expected and observed behavior, and the potential impact.
Use local test accounts and synthetic funds. Do not send private keys, seed
phrases, credentials or personal information.

If the issue also affects the upstream engine or program, identify the affected
upstream revision so the maintainers can coordinate a report.

## Scope and verification

Reports concerning accounting, authorization, oracle validation, custody,
liquidation, withdrawal behavior or transaction rollback are particularly
relevant. Public test and proof artifacts describe their own scope; they do
not constitute an independent security audit of Outright.
